# Демонстрационное хранилище

> Русский · [English](README.md)

Готовое хранилище, чтобы попробовать Projects Plus: заметки с заполненными полями, связи между
папками и Dashboard, который стоит собрать своими руками. Откройте его как хранилище Obsidian и
пройдите по шагам ниже.

## Подготовка

1. Скопируйте `main.js`, `manifest.json` и `styles.css` из корня проекта в
   `demo-vault/.obsidian/plugins/obs-projects-plus/`
2. Откройте `demo-vault` как хранилище Obsidian
3. Включите «OBS Projects Plus» в Настройки → Сторонние плагины
4. `Ctrl/Cmd+P` → «Projects Plus: Create Project» → выберите папку `Projects/`

## Структура

| Папка | Зачем | Заметки |
|--------|---------|-------|
| `Projects/` | основной источник данных (папка) | 22 заметки задач и проектов |
| `Team/` | цели связей | 4 заметки сотрудников — объявлены как поле `relation` в настройке полей |
| `Clients/` | пример объединения источников | 4 заметки клиентов — добавьте вторым источником |

## Что уже настроено

В `data.json` заранее лежит:

- **Два проекта**: «Demo Project» (`Projects/`) и «Team Members» (`Team/`)
- **Связи между источниками**: поля `assignee` и `reviewer` объявлены как `relation` на Team Members
- **Типы полей**: `status` с цветовыми группами, `priority` как список с цветами
- **Dashboard**: вкладки фильтра (по статусу), обзор с четырьмя карточками и блок данных в виде таблицы
- **Поля-формулы**: `Budget Utilization` (`ROUND(spent / budget * 100, 1)`) и `Days Remaining`
  (`DATE_BETWEEN(TODAY(), due, "day")`)
- **Строка итогов**: сумма по `budget`, сумма по `spent`, среднее по `progress`, сумма по `hours`

## Что можно посмотреть

### Поля frontmatter в заметках

| Поле | Тип | Где используется | Что показывает |
|-------|------|------------|----------------|
| `status` | текст (todo/in-progress/done/blocked) | все заметки | группировка на доске, фильтры |
| `priority` | текст (critical/high/medium/low) | все заметки | условное форматирование, сортировка |
| `startDate` / `endDate` | дата | многодневные задачи | многодневные полосы в календаре |
| `startTime` / `endTime` | время | встречи | слоты на таймлайне календаря |
| `date` | дата | все заметки | запасная дата в календаре, дата создания |
| `due` | дата | дедлайны | фильтры is-overdue, is-upcoming |
| `color` | цвет HEX | отдельные заметки | цвет в календаре |
| `assignee` | `[[ссылка]]` | все заметки | **поле-связь** → заметки `Team/` |
| `reviewer` | `[[ссылка]]` | часть заметок | вторая связь |
| `tags` | список | все заметки | группировка по тегам, вкладки фильтра |
| `category` | текст | все заметки | вкладки фильтра, группировка на доске |
| `type` | текст | все заметки | группировка на графике |
| `progress` | число (0–100) | отслеживаемые задачи | график прогресса, условное форматирование |
| `budget` | число | финансовые задачи | сумма, среднее, финансовые формулы |
| `spent` | число | финансовые задачи | графики против `budget`, формулы |
| `hours` | число | задачи с учётом времени | формулы длительности, сводки |
| `completed` | да/нет | задачи-чеклисты | блок чеклиста |
| `sprint` | текст | задачи спринта | группировка столбчатого графика |
| `risk` | текст (low/medium/high) | часть задач | измерение на точечном графике |
| `score` | число | оценённые записи | статистические формулы |

### Представления, которые стоит настроить

| Представление | Настройка | Что показывает |
|------|---------------|---------------|
| **Доска** | группировка по `status` | канбан, колонки на месте, перетаскивание карточек |
| **Календарь** | дата=`startDate`, окончание=`endDate`, время=`startTime`/`endTime`, цвет=`color` | таймлайн, многодневные полосы, слоты времени, цвета |
| **Галерея** | заголовок + приоритет + исполнитель | просмотр карточками |
| **Dashboard** | см. блоки ниже | блоки, графики, итоги |

### Блоки Dashboard, которые стоит добавить

| Блок | Настройка | Что показывает |
|-------|---------------|--------------|
| **Database** (вид «таблица») | все поля, группировка по `category` | сортировка, фильтры, правка ячеек, условное форматирование, связи |
| **Database** (вид «доска» / «календарь» / «галерея») | тот же источник, другой вид | один блок показывает данные так, как нужно задаче |
| **Chart (столбчатый)** | X=`assignee`, Y=количество | столбчатый график |
| **Chart (круговой)** | X=`status` | распределение по статусам |
| **Chart (точечный)** | X=`budget`, Y=`progress`, цвет=`priority` | точечный график с линией тренда |
| **Chart (столбчатый с накоплением)** | X=`sprint`, накопление=`status` | накопление по статусам |
| **Chart (линейный)** | X=`date`, Y=`progress` | динамика во времени |
| **Stats** | `budget`: сумма, среднее, максимум; `progress`: среднее, медиана | карточки сводки |
| **Checklist** | поле=`completed` | список с переключателями |
| **Filter Tabs** | поле=`category` | быстрый фильтр по категории |
| **Text / Divider / Cover Banner** | — | заголовки, разделители и картинка-шапка на полотне |

### Формулы, которые можно попробовать

```
# Финансы
PMT(0.05/12, 360, -budget)         → ежемесячный платёж
NPV(0.1, budget, spent)            → чистая приведённая стоимость
IRR([-budget, spent, spent])        → внутренняя норма доходности

# Статистика
VARIANCE(@score)                    → дисперсия по всем оценкам
PERCENTILE(@progress, 0.75)         → 75-й процентиль прогресса
CORREL(@budget, @progress)          → корреляция бюджета и прогресса

# Даты
DATE_BETWEEN(endDate, startDate)    → длительность в днях
FORMAT_DATE(due, "MMM DD")          → дата в заданном формате
WORKDAYS(startDate, endDate)        → только рабочие дни

# Условия
IF(progress > 80, "✅", IF(progress > 50, "🔶", "🔴"))
SWITCH(priority, "critical", 4, "high", 3, "medium", 2, 1)

# Агрегация
SUM(@budget)                        → общий бюджет
COUNTIF(@status, "done")            → сколько завершено
AVERAGEIF(@progress, ">50")         → средний прогресс по продвинутым задачам

# Строки
REGEX_MATCH(tags, "bug|fix")        → найти связанное с багами
JOIN(@assignee, ", ")               → все исполнители одной строкой
```

### Объединение двух источников

1. Создайте проект с `Projects/` как основным источником
2. Добавьте `Clients/` дополнительным источником (Настройки → дополнительные источники)
3. Данные обеих папок появятся в одном представлении

### Операторы фильтра, которые стоит проверить

- `is-today` — заметки с сегодняшней датой
- `is-overdue` — заметки, у которых `due` раньше сегодня
- `is-upcoming` — заметки, у которых `due` в будущем
- `is-this-week` / `is-this-month` / `is-this-quarter`
- `contains` / `not-contains` — поиск по тексту
- `has-any-of` / `has-all-of` — совпадение по тегам и спискам
