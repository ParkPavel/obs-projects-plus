# 📋 Шаблоны Projects Plus

> Русский · [English](README-EN.md)

Коллекция Templater-шаблонов для плагина **Projects Plus**. Все шаблоны используют стандартные поля плагина и интерактивные диалоги выбора.

## 🚀 Быстрый старт

1. Установите [Templater](https://github.com/SilentVoid13/Templater)
2. Скопируйте шаблоны в папку шаблонов вашего хранилища
3. Настройте Templater: `Settings → Templater → Template folder location`
4. Создавайте заметки через `Alt+N` → `Templater: Create new note from template`

## 📊 Стандартные поля

Все шаблоны используют поля из демо-проекта плагина:

| Поле | Тип | Описание |
|------|-----|----------|
| `title` | текст | Название заметки |
| `startDate` | YYYY-MM-DD | Дата начала события (определяет позицию в календаре) |
| `date` | YYYY-MM-DD | Дата создания заметки (автозаполнение, не влияет на позицию) |
| `endDate` | YYYY-MM-DD | Дата окончания (для многодневных событий) |
| `startTime` | HH:mm | Время начала |
| `endTime` | HH:mm | Время окончания |
| `status` | inbox/todo/doing/done | Статус задачи |
| `completed` | true/false | Флаг завершения |
| `priority` | high/medium/low | Приоритет |
| `color` | HEX | Цвет в календаре |
| `type` | встреча/задача/баг/событие | Тип записи |
| `category` | работа/разработка/личное... | Категория |
| `estimate` | число | Оценка времени (часы) |
| `tags` | список | Теги для фильтрации |

> **Важно**: Поле `startDate` определяет, на какую дату в календаре попадёт событие. Поле `date` — это дата создания заметки, которая автоматически заполняется при создании и **не участвует** в определении позиции события.
