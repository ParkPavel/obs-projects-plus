05 / GET STARTED

Start with a handful of notes.

Download main.js, manifest.json and styles.css from the same stable release. Put them in the folder below and enable Projects Plus in Obsidian. Replace .obsidian if you use a custom configuration folder.

.obsidian/plugins/obs-projects-plus/

Open stable releases ↗

Keep data.json when updating, and back up your vault. This file contains your project and view settings.

A few useful details.

Where does my data live?

Records are Markdown files in your vault. Projects and view settings live in .obsidian/plugins/obs-projects-plus/data.json.

Do I need Dataview?

No. Folder, tag and built-in query sources work without it. Dataview is only needed when you choose that source.

Is there a server or analytics?

The plugin has no separate server or telemetry. External covers and images can load over the network; use vault images for local-only content.

Does it work on a phone?

The plugin targets desktop and mobile Obsidian. Gesture behaviour depends on the device; check the notes for your installed release.

Can I edit every value?

Ordinary writable properties can be edited. Formulas, rollups and transformed results may be calculated and unavailable for direct editing.
